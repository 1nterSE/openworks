Preparing quotes in ChatGPT

x-crm-ai, built by Mikhail for a heating and cooling business.

Need
Reuse quote templates and past proposals without uploading them again in every chat.
Tool
Staff can save a template or quote, then ask ChatGPT in a new chat to retrieve it and draft an updated version. A manager checks prices and technical details before sending.
Owner input
Document work stays in ChatGPT at the owner's request; staff can retrieve original files using ordinary language.
In use
Employees use the system to keep records and fill out PDFs. We trained them to use it.

Automotive parts · Working product

MileParts

AI tools for auto dismantlers selling used parts on eBay.

Need
Keeping prices and listings up to date across a large inventory takes time.
Tool
Compares prices in active competing listings, suggests updates within limits set by the seller, and helps improve and relist older listings. Sellers can approve changes or choose automatic updates.
In use
Used by sellers.
Training
We provide full onboarding, showing users how AI suggests price updates for their eBay stores and how to review them. We explain that AI handles routine work but can make mistakes and needs human oversight. We use their feedback to improve the product.
